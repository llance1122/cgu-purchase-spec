# 請購規範確認表產生器

輸入產品網址或型號，自動查規格並產出填好的 Word 檔，格式與空白範本完全一致。

單一 HTML 檔，**雙擊就能用**。沒有後端、不需要安裝、不需要伺服器。

後端接長庚大學的 [CGU AI Resources](https://air.cgu.edu.tw/) LLM API。

---

## 線上直接用

**https://llance1122.github.io/cgu-purchase-spec/**

開啟後填入自己的 CGU API Key 即可。金鑰存在你自己的瀏覽器，不會傳給任何人。

想離線使用的話，下載 `output/請購規範產生器.html` 雙擊開啟，功能完全相同。

## 使用步驟

1. **設定** —— 貼上 CGU API Key（到 [AIR 平台](https://air.cgu.edu.tw/workspace4/LLMAPI/index.php) 取得）
2. **基本資料** —— 填規格代號、材料編號，產品欄貼網址或直接輸入型號
3. **查詢規格** —— 自動上網查，結果填入下方
4. **確認與修改** —— 每一格都能改，改完再產生
5. **產生 Word 檔** —— 直接下載

金鑰只存在你這台電腦的瀏覽器 localStorage —— 這個工具沒有後端，不會上傳到任何地方。

### 多組金鑰

設定區可加入多組並命名（例如「個人」「系上」），下拉切換，切換後額度會重新載入。

### 資料來源

查詢結果下方會列出網址供核對，包含 `web_search` 實際引用的頁面與模型自己列的來源，
重複的會合併。「查到的原始資料」可展開，看模型整理前拿到的完整文字 ——
要追查某條規格的出處，這個比來源清單更有用。

## 表格內容

| 欄位 | 來源 |
| --- | --- |
| 材料規範名稱 | 自動產生中文通用品名，可改 |
| 規格代號、材料編號 | 手動輸入 |
| 公司、請購部門 | 範本固定值，不會被動到 |
| 建檔/列印日 | 當天，可改 |

規格列的排法：

| 項次 | 規格名稱 | 品質標準 |
| --- | --- | --- |
| 1–N | 產品規格項目 | 照抄實際規格 |
| N+1 | 推薦型號 | 如 &lt;廠牌型號&gt; &lt;中文品名&gt; |
| N+2 | 其他 | 為符合教育部規定，採購資通訊產品不得使用大陸廠牌（僅資通訊產品） |
| N+3 | 保固 | 原廠保固三年… |

項次欄留空會自動編號。列數不固定，可自由增減、調整順序。

### 兩條硬規則

單一儲存格 **100 字元以內**、**不使用列點**。

字數即時顯示在每格下方，超過會變紅並**禁用產生按鈕**，不會產出不合規的檔案。

## 換範本

範本以 base64 內嵌在 HTML 裡，所以整個工具只有一個檔案。
換掉 `template.docx` 之後要重新建置：

```
node build-web.js
```

會產生新的 `output/請購規範產生器.html`。

---

## 架構

```
web/index.html      原始檔（含 __TEMPLATE_B64__ 佔位符，不能直接開）
build-web.js        把範本內嵌進去，產出可用的單檔
template.docx       空白範本
output/             建置產物，離線使用時開這個
docs/index.html     同一份內容，供 GitHub Pages 提供服務
```

`output/` 與 `docs/` 是同一份檔案的兩個複本，只是檔名不同 ——
前者給人下載後雙擊，後者讓 Pages 的網址乾淨。`build-web.js` 會同時產生兩者。

**不要直接開 `web/index.html`** —— 那是未建置的原始檔。真的開了會跳出提示告訴你開錯了。

### 幾個實作決定

**直接改範本的 XML**，不是用程式重畫表格。所以邊框、字體、底色、合併儲存格、
廠商報價須知都與範本一模一樣。

**自己實作 zip 讀寫**（用瀏覽器內建的 `DecompressionStream` / `CompressionStream`），
沒有引入任何外部函式庫。重點是保留項目順序 —— Office 要求 `[Content_Types].xml`
必須是壓縮檔的第一個項目。

**產生前檢查 XML 標籤平衡。** 曾經因為重建表格時弄丟 `</w:tbl>`，產出的 zip 完全正常、
Word 卻打不開，光驗證壓縮檔看不出來。

**網址交給模型去讀**，瀏覽器不直接抓產品頁面 —— 那會踩到對方網站的 CORS。

## 已知限制

**規格正確性要人工複核。** 模型會照抄查到的規格，但查錯頁面或抓到舊型號都有可能。
產生前務必看過來源網址。頁面下方也有固定提醒。

**動態網頁可能查不到。** 規格靠 JavaScript 載入的頁面模型不一定讀得到，
這種情況改用型號輸入。

**若出現「連線被擋下」**，代表瀏覽器封鎖了本機網頁對外請求。
把檔案放到一個資料夾後執行 `python -m http.server 8000`，改開 `http://localhost:8000/`。
